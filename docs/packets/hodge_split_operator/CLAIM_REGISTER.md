Use the repository's four-tier vocabulary. No statement moves upward without a receipt.

## Claim movement gates

### Speculative -> Plausible

Requires a complete formal definition, one non-trivial fixture, and a null comparison.

### Plausible -> Observed

Requires reproducible code, declared conventions, passing reconstruction receipts, conservation residuals, and at least one counterexample boundary.

### Observed -> External

Requires independent mathematical review and a separate public claim audit. Repository inclusion alone is not external validation.
