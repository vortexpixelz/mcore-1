# Codespace Start Guide

## Mission

Run the AI7 schema selection experiment against Bundle 1.

## First 20 minutes

1. Open this folder:

```bash
cd docs/packets/ai7/schema_experiment
```

2. Paste the dated Bundle 1 material into:

```text
source_bundle_notes.md
```

3. Do not score anything yet.

4. Backfill the same source notes into each schema:

```text
schema_A_minimal_grant.md
schema_B_research_ledger.md
schema_C_table_flip.md
schema_D_cockpit.md
```

5. Only after all four are filled, score them in:

```text
scorecard.yaml
```

6. Write the winner and next action in:

```text
result_memo.md
```

## Anti-goblin rule

No schema wins until every schema touches the same source bundle.
