# AI7 Schema Experiment Workspace

This folder is the working cockpit for the schema selection experiment.

## Goal

Compare packet schemas against the same source bundle and choose the schema that best supports research memory, evidence discipline, and action generation.

## Files to create

```text
source_bundle_notes.md
schema_A_minimal_grant.md
schema_B_research_ledger.md
schema_C_table_flip.md
schema_D_cockpit.md
scorecard.yaml
result_memo.md
```

## First rule

Fill `source_bundle_notes.md` before judging schemas.

The bundle is the substrate. The schemas are lenses. Do not let the lenses rewrite the substrate too early.
