# Schema Object Model

This experiment treats a schema as an object, not just a template.

## Schema object

```yaml
schema_id:
schema_version:
fields:
required_separations:
scoring_notes:
failure_modes:
```

## What a schema can preserve

- evidence
- claims
- uncertainty
- next actions
- reviewer translation
- retrieval keys

## What a schema can break

- nuance
- provenance
- action clarity
- claim discipline
- human readability
- machine parsability

## Research question

A schema is good if it improves memory and decision quality without laundering speculation into fact.
