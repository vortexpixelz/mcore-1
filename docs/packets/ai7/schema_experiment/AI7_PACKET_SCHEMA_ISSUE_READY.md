# AI7 Packet Schema Issue Ready Note

This folder supports the GitHub issue for the AI7 schema-selection experiment.

## Why this matters

Bundle 1 is not just a document to summarize. It is a dated packet that can be used as a test substrate for memory schema design.

## Main question

Can we compare schemas the way MCORE compares perturbations?

## Practical answer

Yes, at a small scale:

1. Same input bundle.
2. Multiple schemas.
3. Same scoring rubric.
4. Result memo.
5. Winner or hybrid template.

## Success

By the end, AI7 has a packet template that is easier to fill, easier to retrieve, and safer for external claims.
