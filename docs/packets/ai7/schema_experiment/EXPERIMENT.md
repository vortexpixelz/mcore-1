# Experiment Summary

Treat schemas as selectable memory objects.

## Input

One dated source bundle: Bundle 1.

## Transform

Backfill Bundle 1 into multiple schemas.

## Score

Use the same rubric for every schema.

## Select

Choose the schema or hybrid that best supports:

- retrieval
- compression
- claim discipline
- actionability
- reviewer readiness

## Output

A reusable AI7 packet template and one next action.
