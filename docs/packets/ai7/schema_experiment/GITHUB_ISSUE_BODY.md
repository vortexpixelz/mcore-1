# Experiment: Treat packet schemas as selectable memory objects

## Objective

Run a small experiment that treats packet schemas as first-class objects that can be filled, scored, compared, and selected.

## Research question

What schema best preserves a dated research bundle as useful memory while producing one judgeable AI7 next action?

## Workspace

```text
docs/packets/ai7/schema_experiment/
```

Start here:

```bash
cd docs/packets/ai7/schema_experiment
cat CODESPACE_START.md
```

## Acceptance criteria

- [ ] Capture Bundle 1 in `source_bundle_notes.md`.
- [ ] Fill at least three schema variants from the same source bundle.
- [ ] Complete `scorecard.yaml` with 1-10 scores and notes.
- [ ] Complete `result_memo.md` with a provisional winner.
- [ ] Update `TEMPLATE_AI7_PACKET_WINNER.md`.
- [ ] End with exactly one AI7 next action.
