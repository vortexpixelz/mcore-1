# Schema Factory

The Schema Factory treats packet schemas as selectable research-memory objects.

It starts from the AI7 schema-selection issue and may later become a reusable factory for other Symonic / MCORE packets.

## Current issue

- GitHub issue: #37
- Workspace: `docs/packets/ai7/schema_experiment/`

## Factory idea

A factory run takes:

1. one source bundle,
2. multiple candidate schemas,
3. one scoring rubric,
4. one result memo,
5. one promoted template.

## Current status

This is a placeholder experimental lane. The first actual run is still manual and lives in the AI7 docs workspace.

## Next action

Run the AI7 schema experiment manually first. Only automate after the manual scoring loop proves useful.
